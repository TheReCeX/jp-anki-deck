# Templates

Card templates, note type definitions and CSS of the deck (generated by `scripts/export.py`, used by `scripts/build.py`).

| Path | Content |
|------|---------|
| `style.css` | Shared CSS |
| `Japanese/` | Vocabulary note type: `Recognition` and `Recall` cards, `notetype.json`, `fields.txt` |
| `Japanisch_Anleitung/` | Guide card (DE/EN) |

Editing these files and running `python scripts/build.py` updates the note types in your collection on import. See [`scripts/README.md`](../scripts/README.md).
