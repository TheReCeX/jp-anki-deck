# jp-anki-deck

Anki-Deck „Japanisch“ (Genki + Tobira) mit eigenen Kartenvorlagen, zweisprachig (Deutsch/Englisch).

## Features
- Zweisprachig: Umschalter DE/EN in den Karteneinstellungen (Zahnrad-Panel)
- Funktionen einzeln per Schalter ein-/ausblendbar
- Kanji-Popup (Strichfolge, Kanji-Infos) für alle Kanji
- Läuft offline, auch auf dem Handy (AnkiMobile, AnkiDroid) – kein Desktop-Add-on nötig
- Schrift: Sawarabi Mincho

## Optionales Desktop-Add-on
Kanji-Wortindex: [AnkiWeb](https://ankiweb.net/shared/info/1607352118) (Code `1607352118`)
